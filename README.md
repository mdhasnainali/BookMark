# BookMark 🔖

A modern, responsive bookmark management application built with React and Vite.

## About

**BookMark** is a frontend application designed to help users organize, manage, and access their bookmarks efficiently. With a clean and intuitive user interface, BookMark provides a seamless experience for bookmark management.

## Features

✨ **Modern UI** - Clean, responsive design built with Tailwind CSS  
⚡ **Fast Performance** - Powered by Vite for optimal development and production builds  
🧭 **Easy Navigation** - Intuitive routing with React Router  
📡 **API Integration** - Axios for seamless HTTP communication  
🎨 **Accessible Components** - Beautiful icons from Heroicons  
🔍 **Smart Selection** - Advanced dropdown selections with React Select  
✅ **Code Quality** - ESLint configured for React best practices

## Tech Stack

- **Frontend Framework**: React 18
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **Routing**: React Router DOM v6
- **HTTP Client**: Axios
- **Icons**: Heroicons React
- **Select Library**: React Select
- **Linting**: ESLint

## Getting Started

### Prerequisites
- Node.js (v16 or higher)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/mdhasnainali/BookMark.git
cd BookMark

# Install dependencies
npm install
```

### Development

```bash
# Start the development server
npm run dev
```

The application will be available at `http://localhost:5173` (default Vite port)

### Build

```bash
# Build for production
npm run build
```

### Preview

```bash
# Preview the production build locally
npm run preview
```

### Linting

```bash
# Run ESLint to check code quality
npm run lint
```
